Double Instruction Executor

Executes two-dimensional instructions over columns and data, validates before dispatch, and writes the result to destinationPath.

Purpose

Executes two-dimensional instructions over columns and data, validates before dispatch, and writes the result to destinationPath.

Shared instruction contract

{
  "sourcePath": { "fileName": "data", "filePath": ["rows"] },
  "destinationPath": { "fileName": "table", "filePath": ["tbody", "children"] },
  "func": "fromCollection",
  "templateKey": "row",
  "narration": "Build table rows"
}

The exact function and paths must match the registered functions, registry structure, and templates used by the consumer. The example illustrates the field shape; it is not a promise that every package registers the same functions.

Pipeline

  1. Describe the transformation as JSON.
  2. Validate the instruction shape with the guards package.
  3. Dispatch to the appropriate single or double executor.
  4. Write the generated result to the destination path.
  5. Use the resulting specification in the downstream renderer.

Development

Keep implementation in versioned src/vN directories and expose only the intended current version from src/index.js. Run the package's test script when present. A successful static file check is not a substitute for runtime integration tests.
